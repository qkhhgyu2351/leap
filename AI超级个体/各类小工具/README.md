# 增重教练项目

本项目包含一个智能的个性化增重教练应用，帮助用户实现科学增重目标。

## 项目内容

```
长胖工具/
├── bulking-coach.html   # 增重教练应用（单文件，双击即可打开）
└── README.md
```

单文件静态应用，无后端、无构建步骤。

## 如何使用

1. 双击 `bulking-coach.html`
2. 完成入职流程，创建个性化增重计划
3. 开始记录每日体重和饮食

## 核心功能

- 个性化增重计划生成
- 科学的热量和蛋白质目标计算
- 分阶段增重策略
- 智能建议系统
- 数据可视化图表
- PWA支持，可添加到主屏幕

## 技术特点

- 基于BMR和TDEE的科学算法
- 响应式设计，支持所有设备
- 本地数据存储，完全隐私
- 现代化UI界面
- 实时数据可视化
