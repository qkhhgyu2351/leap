## 3. 推荐方案 A 详解（Waline 私有部署）

### 3.1 架构

```
浏览器 article.html
   └─ <div id="waline"> + JS
        └─ 调用 https://aicfo.site/api  (你的评论后端)
              └─ nginx 反代 → 127.0.0.1:8360 (Waline Node 服务)
                    └─ SQLite 文件 (数据在你服务器)
```

### 3.2 前端改动（仅 `article.html`，文档给出，实施时再写入）

在 `<main class="article">` 内、footer 之前插入评论区：

```html
<!-- 在 </main> 之前插入 -->
<section id="comments" class="comments">
  <h2 class="comments-title">评论</h2>
  <div id="waline"></div>
</section>

<!-- 样式：浅底、深字，与站点一致；不暗底 -->
<style>
  .comments{margin-top:40px;border-top:1px solid var(--line);padding-top:28px}
  .comments-title{font-size:18px;color:var(--brand);margin-bottom:16px}
  /* Waline 自带浅色主题，无需额外改；如要微调可覆盖 .wl- 变量 */
</style>

<!-- 脚本：建议自托管 vendor（与站点现有 vendor/ 一致，避免 unpkg 国内慢） -->
<link rel="stylesheet" href="./vendor/waline/waline.css" />
<script src="./vendor/waline/waline.js"></script>
<script>
  Waline.init({
    el: '#waline',
    serverURL: 'https://aicfo.site/api',  // 备案后换成你的域名
    pageview: true,
    comment: true,
    login: 'disable',        // 关键：关闭登录 = 纯匿名
    lang: 'zh-CN',
    requiredMeta: ['nick'],  // 只需昵称，邮箱/网址可选
    emoji: []                // 可留空或自托管表情包
  });
</script>
```

> 注意：Waline 的 JS/CSS 建议**自托管**到 `AI首席网站/vendor/waline/`，
> 与现有 `vendor/` 思路一致，避免 unpkg/jsdelivr 国内访问慢。实施时把这两个文件下载进 vendor。

### 3.3 服务器部署（你执行，我给脚本）

**方式一：Docker（最省事，推荐）**

```bash
# 在 182.92.62.52 上
docker run -d --name waline \
  -e SQLITE_PATH=/data \
  -e JWT_TOKEN=换成你自己的随机长字符串 \
  -e WALINE_FORBIDDEN_WORDS=广告,加微信,代操盘,内幕,涨停,稳赚  # 屏蔽词
  -v /opt/waline:/data \
  -p 8360:8360 \
  lizheming/waline:latest
```

**方式二：Node 直接跑**

```bash
npm init -y
npm i @waline/vercel
# 用 pm2 守护
npm i -g pm2
pm2 start node_modules/@waline/vercel/vanilla.js --name waline
# 或 docker 同上，更简单
```

**nginx 反代**（在你现有 nginx 配置里加一段 server block，或挂到 aicfo.site 的 block 下）：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8360/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

**管理后台**：访问 `https://aicfo.site/ui`，用 `JWT_TOKEN` 登录，可删评、审核、看通知。

## 4. 方案 B 详解（海外托管先试）

最快看到效果，适合备案前验证产品形态：

1. 在 Vercel / Cloudflare Pages 部署 Waline（官方有模板，连 SQLite/Postgres）。
2. 拿到后端地址（如 `https://your-waline.vercel.app`）。
3. 前端 `serverURL` 填该地址，`login:'disable'`。
4. 我直接把 `article.html` 接好即可。

**缺点**：Vercel 国内偶发卡；备案前用海外服务承载 UGC，法理偏灰，不要正式对外推。

## 5. 方案 C 详解（复用小程序后端）

- 在现有 NestJS 加 `CommentsModule`：表 `comments(id, post_id, nick, content, status, created_at)`。
- 接口：`POST /comments`（匿名提交，status 默认 pending）、`GET /comments/:postId`（只返回 approved）。
- 前端 `article.html` 用 fetch 调接口，自己写评论组件。
- 优点：数据进你已有库、最可控、可做后续会员/审核流。
- 缺点：要后端上线 + nginx 反代 + 前端组件，工作量最大。

## 6. 合规护栏（必须，你重视合规）

匿名评论 = UGC（用户生成内容），财经内容尤其敏感：

1. **备案前提**：aicfo.site 还在 ICP 备案中。非经营性备案通常不允许直接 UGC；
   上线评论前，备案时如实申报，或等备案通过再开。
2. **匿名但留痕**：虽免注册，建议记录 IP（Waline 默认记），出事可溯源。
3. **屏蔽词**：用 `WALINE_FORBIDDEN_WORDS` 屏蔽荐股/不当词汇（见 3.3）。
4. **审核机制**：Waline 后台可逐条删评；建议开启"先发后审"或定期巡查。
5. **防刷/防垃圾**：接腾讯云验证码（Turnstile/recaptcha）或 Akismet；Waline 内置频率限制。
6. **免责声明**：评论区上方加一行"评论仅代表用户个人观点，与本站无关"。
7. **内容安全（可选）**：量大时接腾讯云天御内容安全 webhook，自动拦截违规。
