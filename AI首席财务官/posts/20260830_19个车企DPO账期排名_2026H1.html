方法论

DPO 公式：应付合计(期末) × 365 ÷ (营业成本 H1 × 2)

应付合计 = 应付账款 + 应付票据（合并计算，未单列中小企业账期）。

阈值 144 天 = 60 天中小企业账期承诺 × 2.4。注：60 天账期承诺仅适用于大型企业对中小企业的付款（《保障中小企业款项支付条例》修订版，2025-06-01 施行），并非对所有供应商；各公司亦不单独披露对中小企业的付款账期，故 DPO 总额为唯一可量化指标。

比率与单位无关（千元 / 百万元 / 元 / 美元百万口径下比值一致），仅相对规模影响天数。

DPO 账期排名（天，降序）

超阈值（>144 天，占上游最狠） 未超阈值（≤144 天） 144 天 = 60 天账期承诺 × 2.4

口径与风险提示

1. 小米汽车：经核验 2026 半年报资产负债表无单独应付票据科目，DPO 按貿易應付款項（1183.28 亿，应付口径全额）计算，口径完整，不存在偏低。

2. 特斯拉：原币为美元，DPO 仅作比率比较，绝对数值不可与其他人民币口径直接加总。

3. 北汽蓝谷：本会话发现原下载文件误为江苏艾迪药业（688488），已通过公告 ID 1225527313 重新下载正确 600733 半年报（139 页）并覆盖、镜像、字节比对。

4. DPO 采用期末应付合计（非平均余额），对季节性较强的公司会放大波动；H1 营业成本 ×2 年化存在口径近似。

5. 60 天账期承诺仅约束大型企业对中小企业的付款，不等于全部供应商账期；各家不单独披露对中小企业付款账期，故本表不区分。

6. 2026-08-30 文件身份核验：已对 18 份 H1 报告逐份打开封面页，核对公司名 + 股票代码（上汽 600104 / 广汽 601238 / 长安 000625 / 北汽蓝谷 600733 / 江淮 600418 / 赛力斯 601127 / 长城 601633 / 小鹏 XPeng 9868 / 岚图 VOYAH 等），确认无错公司混入。唯一历史错件（北汽蓝谷曾误收艾迪药业 688488）已于本会话更正。注意：本核验覆盖「文件身份 + DPO 所用关键数（应付合计、营业成本）」，非全科目逐页审计。
