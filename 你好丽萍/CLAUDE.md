# 「你好丽萍」项目规则

## 一、读写边界（最高优先级，永远遵守）

**唯一可写目录：** `download/leaping/你好丽萍/`

- 所有新建、修改、删除，只在这个文件夹里进行。
- 站点结构：`index.html`（首页信息流·今时往日）、`entry.html`（单条详情）、`archive.html`（全量文字清单·往日页）、`entries.js`（唯一数据源）、`site.js`、`site.css`、`assets/`。
- 注意：**没有「忆.html」**——该页早已删除，全站信息流已合并进 `entries.js`。不要再去建或找"忆页"。

**只读目录：** `download/txt/`

- 这是素材库，**只读取，绝不写入、修改、移动、删除任何文件**。
- 需要用里面的素材时，读取内容后写进 `你好丽萍/`，不回写原处。

**其他目录**（`leaping/AI首席/`、`leaping/other/`、各 backup 文件夹）：非本项目请求不动。

### 关于解密数据库（高度敏感）

`workplace/decrypted_dbs/` 是**全量微信明文库**，不只一个会话：

- 395 个会话表，103,295 条消息
- 联系人 19,601、群聊 205、群成员记录 17,668
- 表名 = `Msg_` + md5(微信号)，可用 `contact.db` 反查真实身份

**处理原则：**

1. 未经明确指示，不读取任何会话内容。
2. 读取过的他人聊天内容，**不写入任何文件**，只在当次对话中呈现。
3. 上站的内容必须由本人筛选确认，涉及他人私人表达的一律不自行采用。

## 三、写作与内容

- 站是公开的（leaping.site）。发布前先分清：哪些是本人的记录，哪些是他人的私人表达。
- `entries.js` 是全站唯一信息流，字段说明写在文件头部注释里，新增条目照格式追加。
- 内容基于真实素材，不虚构、不臆想。资料不全就说资料不全。
